# ניתוח: "מלך השינועים" — מודעה מאוירת עם דמויות

מקור: `עיתון_פותחים_שבוע_טז_אלול/ads/page_22_ad_01.jpg`

## archetype
`graphic` (עם אלמנט מאויר, לא מצולם — ראו הסתייגות למטה)

## summary_he
מודעת חברת הובלות עם המון אנרגיה חזותית: משאית וזוג דמויות מאוירות (סגנון קומיקס/מגזין חרדי) מעמיסות
קופסאות, כוכבית פיצוץ עם "רכב ונהג בלבד!", כותרת צהובה-לבנה גדולה עם כתר, בועת דיבור כחולה, ומספר טלפון
ענק בתחתית לצד דמות שלישית (מסקוט) שמניפה אגודל. זו מודעה "רועשת" בכוונה — הרבה יותר קרובה לאיור מגזין
מאשר לצילום מוצר.

## elements
כלי הצילום הפוטוריאלי (Gemini image, chroma-key) **לא מתאים** לסגנון האיור השטוח-קומיקסי הזה — ניסיון
ליצור אותו כ"photorealistic advertising photography" (כפי ש-`elementPrompt` מנסח כל אלמנט) ייצר תוצאה שלא
תואמת בכלל. זו מגבלה אמיתית וכנה של המערכת: **סגנון איור שטוח (flat illustration / קומיקס) לא נתמך היום**,
רק "פוטוריאליסטי" (elements) או "גרפי-טיפוגרפי" (panels+lines). הדרך המעשית לשחזר את המודעה הזו בקונספטה
כיום: להעלות לוגו/איור מוכן כ"צילום" (element kind=object, "העלאת צילום" במקום generate), ולבנות סביבו
פאנלים+טקסט. לכן בטבלה למטה `kind` מסומן `object (uploaded, not generated)`.

| kind | name | הערה |
|---|---|---|
| object (uploaded, not generated) | איור המשאית + דמויות | גרפיקה מוכנה שהלקוח מספק, לא Gemini image |
| object (uploaded, not generated) | מסקוט (דמות עם אגודל) | כנ"ל |

## מתכון לבנייה מחדש בקונספטה (concept_md)

```
# מלך השינועים — מודעה מאוירת

1. סוג מודעה: **גרפית**, אבל עם אזהרה: האיורים עצמם (משאית, דמויות, מסקוט) לא נוצרים ע"י Gemini image
   כי הפרומפטים שלנו כוונו לפוטוריאליזם, לא לאיור שטוח. הפתרון המעשי: להעלות את איורי הלקוח (אם יש לו
   גרפיקאי/מותג קיים) כ"אלמנט" דרך "העלאת צילום" בשלב 6, במקום "יצירה".
2. פאנלים: באנר צהוב לכותרת, פס שחור לסלוגן, אליפסה כחולה לבועת הדיבור, תיבה שחורה לטלפון — ראו טבלה.
3. mandatory.lines: כותרת/סלוגן/בועה/טלפון/שם כפי שמפורט למעלה. שימו לב שהטלפון כאן הוא הכי גדול במודעה —
   size גבוה משמעותית מכל שורה אחרת (זו מודעת "תתקשר עכשיו", לא מודעת מיתוג).
4. **פתוח אמיתי (לא רק בדוגמה הזו)**: תמיכה בסגנון "איור שטוח/קומיקס" כאופציה שלישית ל-elementPrompt,
   לצד photorealistic — כדי שאפשר יהיה גם ליצור איורים כאלה עם Gemini ולא רק להעלות מוכנים.
```
